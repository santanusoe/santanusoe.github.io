# Santanu Soe

Source files for my academic website: [santanusoe.github.io](https://santanusoe.github.io/).

The website presents my research, publications, teaching experience, talks, and academic activities.

## Local development

Install the Ruby dependencies and start the Jekyll development server:

```bash
bundle install
bundle exec jekyll serve
```

The local preview is then available at `http://localhost:4000`.
